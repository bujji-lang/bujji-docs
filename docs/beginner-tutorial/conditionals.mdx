# Conditionals

Conditionals let a program make decisions. In Bujji, the condition comes first,
then `ithe`.

You can read:

<BujjiCode code={`condition ithe:`} />

as:

```text
if condition:
```

## If

Use `ithe` when you want something to happen only if a condition is true.

<BujjiCode code={`age = 20 bujji

age >= 18 ithe:
    "meeru vote cheyyachu" anicheppu`} />

If `age >= 18` is true, the message prints. If it is false, Bujji skips the
indented block.

## If else

Use `leda` for the else block.

<BujjiCode code={`age = 15 bujji

age >= 18 ithe:
    "meeru vote cheyyachu" anicheppu
leda:
    "inka age ravali" anicheppu`} />

Here, only one block runs:

- If the age is 18 or more, the first message prints.
- Otherwise, the `leda` block runs.

## If else-if else

Use `poni condition ithe:` for else-if.

<BujjiCode code={`marks = 72 bujji

marks >= 90 ithe:
    "grade A" anicheppu
poni marks >= 75 ithe:
    "grade B" anicheppu
poni marks >= 50 ithe:
    "grade C" anicheppu
leda:
    "try again" anicheppu`} />

Bujji checks from top to bottom. The first true condition runs, and the remaining
blocks are skipped.

## A complete decision example

<BujjiCode code={`temperature = 32 bujji

temperature > 35 ithe:
    "chala vediga undi" anicheppu
poni temperature > 25 ithe:
    "weather bagundi" anicheppu
leda:
    "challaga undi" anicheppu`} />

This style keeps the decision readable: condition first, then the Telugu-style
decision word.
