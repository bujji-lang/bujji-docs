# Arithmetic Operations

Bujji supports the common arithmetic operations you need for calculations.

| Operation | Symbol | Example |
| --- | --- | --- |
| Addition | `+` | `10 + 5` |
| Subtraction | `-` | `10 - 5` |
| Multiplication | `*` | `10 * 5` |
| Division | `/` | `10 / 5` |
| Remainder | `%` | `10 % 3` |
| Exponential | `^` | `2 ^ 3` |

## Remainder with `%`

The `%` operator gives the remainder after division.

<BujjiCode code={`remainder = 10 % 3 bujji
"remainder is $remainder" anicheppu`} />

`10` divided by `3` leaves `1`, so the remainder is `1`.

## Exponentials with `^`

The `^` operator is used for powers.

<BujjiCode code={`square = 5 ^ 2 bujji
cube = 3 ^ 3 bujji

"5 square is $square" anicheppu
"3 cube is $cube" anicheppu`} />

Here, `5 ^ 2` means 5 multiplied by itself 2 times.

## Using variables in calculations

You can calculate with values stored in variables.

<BujjiCode code={`price = 100 bujji
quantity = 3 bujji

total = price * quantity bujji
"total price is $total" anicheppu`} />

This is the basic pattern for many real programs: store values, calculate with
them, and print the result.
