# While Loops

Loops help a program repeat work. In Bujji, a while-style loop uses `malli`.

You can read:

<BujjiCode code={`malli condition ithe:
    statements`} />

as:

```text
while condition:
    statements
```

The condition is checked before every repeat. If the condition is true, Bujji
runs the indented block. After the block finishes, Bujji goes back and checks the
condition again.

## Counting with `malli`

Here is a simple loop that prints numbers from 1 to 5.

<BujjiCode code={`count = 1 bujji

malli count <= 5 ithe:
    "$count" anicheppu
    count = count + 1 bujji`} />

What happens:

- `count` starts at `1`.
- The loop runs while `count <= 5` is true.
- Each time, Bujji prints `count`.
- Then `count = count + 1 bujji` moves to the next number.

## Stopping early with `aagu`

Use `aagu` to break out of a loop immediately.

<BujjiCode code={`count = 1 bujji

malli count <= 10 ithe:
    count == 6 ithe:
        aagu

    "$count" anicheppu
    count = count + 1 bujji`} />

This loop is allowed to go up to `10`, but it stops when `count == 6`.

Think of `aagu` as "stop here".

## Skipping one round with `chaalu`

Use `chaalu` to skip the rest of the current loop round and continue with the
next round.

<BujjiCode code={`count = 0 bujji

malli count < 5 ithe:
    count = count + 1 bujji

    count == 3 ithe:
        chaalu

    "$count" anicheppu`} />

This prints `1`, `2`, `4`, and `5`. When `count` becomes `3`, `chaalu` skips the
print statement for that round and goes back to check the loop condition again.

Think of `chaalu` as "enough for this round, continue".

## Remember to update the condition

Most beginner loop mistakes happen when the condition never changes.

This is good:

<BujjiCode code={`number = 1 bujji

malli number <= 3 ithe:
    "$number" anicheppu
    number = number + 1 bujji`} />

The loop eventually stops because `number` changes.

This is dangerous:

<BujjiCode code={`number = 1 bujji

malli number <= 3 ithe:
    "$number" anicheppu`} />

Here, `number` stays `1` forever, so the condition always stays true. The loop
does not know when to stop.

## What you learned

- Use `malli condition ithe:` to repeat while a condition is true.
- Use indentation to show which statements belong to the loop.
- Use `aagu` to stop a loop early.
- Use `chaalu` to skip the current round and continue looping.
