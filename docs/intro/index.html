Introduction

Bujji Lang

A new way for Telugu people to talk to computers

Bujji is not an English programming language with Telugu words pasted on top. It is a language designed so Telugu speakers can think, read, and write code closer to the way Telugu sentences naturally form.

user = "Anand" bujji"hello $user" anicheppu
idhi a, b addition:    a + b pampisum = 10, 20 addition bujji"sum is $sum" anicheppu

Why Bujji exists​

Most programming languages teach beginners two things at once: how to solve a problem, and how to express that problem in English-like sentence order. For many Telugu learners, the hard part is not only variables, functions, or loops. The hard part is that the computer expects thoughts to be arranged in a sentence shape that feels imported.

Bujji starts from a different belief: a programming language for Telugu people should respect Telugu thinking. The goal is to make code feel less like translation homework and more like giving clear instructions in a familiar voice.

More than Telugu keywords​

Some languages become "local" by renaming keywords. That helps a little, but the underlying grammar usually stays English-like. Bujji goes deeper. Its keywords are written in romanised Telugu, and its sentence formation follows Telugu-style grammar wherever the language design allows it.

Romanised Telugu keywords

You write words like idhi, bujji, malli, aagu, chaalu, pampi, and anicheppu using English letters, so the language is easy to type on normal keyboards.

Telugu sentence flow

Bujji aims to place meaning in the order a Telugu speaker expects, instead of forcing every idea into English sentence formation first.

Beginner-friendly reading

The syntax tries to make small programs readable out loud. A learner should be able to follow what the code is doing before memorising heavy jargon.

Real programming concepts

Bujji still teaches variables, functions, conditionals, loops, returned values, strings, and expressions. The difference is the path into those ideas.

A small example​

Here is a simple Bujji program that stores a name, defines an addition function, calls it, and prints the result.

functions.bg
user = "Anand" bujji"hello $user" anicheppu
idhi a, b addition:    a + b pampisum = 10, 20 addition bujji"sum is $sum" anicheppu

Read the shape of the program before worrying about every rule:

  • username = "Anand" bujji finishes a statement with bujji.
  • idhi a, b addition: introduces a function-like block.
  • a + b pampi sends the result back from that block.
  • anicheppu asks the computer to say or print something.

The design idea​

Bujji is built around a simple question: what would programming look like if the language met Telugu learners where they already are?

That means the language should not punish someone for thinking in Telugu first. It should let a learner describe values, actions, and results with a rhythm that feels closer to home. Over time, the programmer still learns the universal ideas behind computing, but the first steps feel more welcoming.

The promise of Bujji:

keep programming powerful, but make the conversation with the computer feel natural for Telugu people.

Who Bujji is for​

Bujji is for students, first-time programmers, Telugu-medium learners, teachers, and curious builders who want programming concepts explained through a more familiar language structure. It can also help experienced programmers see how deeply programming languages are shaped by human language, not only by machines.

The long-term dream is simple: when Telugu people learn programming, their first program should not have to sound foreign.
