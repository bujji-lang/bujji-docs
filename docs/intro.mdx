## Why Bujji exists

Most programming languages teach beginners two things at once: how to solve a
problem, and how to express that problem in English-like sentence order. For many
Telugu learners, the hard part is not only variables, functions, or loops. The
hard part is that the computer expects thoughts to be arranged in a sentence
shape that feels imported.

Bujji starts from a different belief: a programming language for Telugu people
should respect Telugu thinking. The goal is to make code feel less like
translation homework and more like giving clear instructions in a familiar voice.

## More than Telugu keywords

Some languages become "local" by renaming keywords. That helps a little, but the
underlying grammar usually stays English-like. Bujji goes deeper. Its keywords
are written in romanised Telugu, and its sentence formation follows Telugu-style
grammar wherever the language design allows it.

Read the shape of the program before worrying about every rule:

- <code>username = "Anand" bujji</code> finishes a statement with
  <code>bujji</code>.
- <code>idhi a, b addition:</code> introduces a function-like block.
- <code>a + b pampi</code> sends the result back from that block.
- <code>anicheppu</code> asks the computer to say or print something.

## The design idea

Bujji is built around a simple question: what would programming look like if the
language met Telugu learners where they already are?

That means the language should not punish someone for thinking in Telugu first.
It should let a learner describe values, actions, and results with a rhythm that
feels closer to home. Over time, the programmer still learns the universal ideas
behind computing, but the first steps feel more welcoming.

## Who Bujji is for

Bujji is for students, first-time programmers, Telugu-medium learners, teachers,
and curious builders who want programming concepts explained through a more
familiar language structure. It can also help experienced programmers see how
deeply programming languages are shaped by human language, not only by machines.

The long-term dream is simple: when Telugu people learn programming, their first
program should not have to sound foreign.
